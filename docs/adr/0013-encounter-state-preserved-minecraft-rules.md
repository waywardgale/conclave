# Preserve ordinary Minecraft rules around encounters

Encounter activity and participant tracking are engine state, so they do not automatically change world interaction, collision, PvP, building, or movement. Conclave applies explicitly authored mechanics and configured modules while ordinary Minecraft and server rules continue, accepting that unrelated players can affect the shared world. This supersedes blanket arena isolation, automatic build protection, and default boundary enforcement, keeping such gameplay behavior an explicit author choice.
