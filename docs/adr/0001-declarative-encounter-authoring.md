# Author encounters through declarative manifests

Conclave will expose gameplay concepts through YAML manifests that humans and AI agents can read and author. YAML can configure and combine existing mechanics into named, parameterized, reusable definitions, including sequencing, simultaneous requirements, branching, and repetition; a new underlying gameplay capability requires a Kotlin extension. Manifests will not expose generic command execution, embedded scripts, or unrestricted expressions, trading arbitrary programmability for understandable encounter definitions and a maintainable extension boundary.
