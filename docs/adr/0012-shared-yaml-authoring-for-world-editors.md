# Use one YAML authoring model for files and in-game editors

Location anchor editors save to the same YAML draft model used by file authors, and publication captures resolved locations and configuration for future attempts. This avoids a second authoritative configuration hidden in placed blocks and keeps changes reviewable and portable for humans and agents. Active attempts retain their starting spatial definitions, and physical anchor edits in occupied arenas wait until those arenas are idle.
