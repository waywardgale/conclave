# Keep each attempt on its starting content revision

Publishing activates a validated YAML revision for future attempts without restarting the server. Every active attempt retains the encounter, mechanic, arena, and other referenced manifest definitions it started with, including balancing values and effective global revival and viewing settings; publishing never changes an active attempt. This gives up mid-attempt hotfix application in exchange for consistent gameplay and avoids migrating running mechanics between definitions. Administrative authority is separate: revoking GM permission takes effect immediately.
