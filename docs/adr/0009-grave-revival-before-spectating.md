# Separate revival at a grave from later spectating

Death first creates a grave and a revival opportunity, with a grave-bound third-person view and only the player's own information. Global configuration controls the combat revive window, revival methods, delays, and later spectator behavior; after the window closes, the participant cannot revive and awaits respawn when the attempt ends. This replaces immediate teammate spectating and allows globally configured unrestricted spectator mode only after the player passes out.
