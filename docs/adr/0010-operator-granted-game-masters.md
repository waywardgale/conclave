# Grant game master status through operator authority

Conclave provides administrative commands and a distinct game master status granted through a designated command available only to the server operator or trusted server console. Gameplay roles, encounter manifests, and command blocks cannot grant this status. Persistent UUID-based membership and immediate revocation let operators delegate attempt control and audited recovery without granting Minecraft OP; exact storage and remote-console policy remain separate decisions.
